# SupplyFlow — Supply Chain Management System

A responsive frontend project built with HTML5, CSS3 and vanilla JavaScript for a web-development internship task.

## Features
- Dashboard KPIs, order activity chart, inventory health chart and alerts
- Supplier Management: create, edit, delete and search suppliers
- Procurement: manage purchase orders
- Inventory: manage stock, warehouses, reorder levels and automatic stock status
- Order Management: customer orders, status and payment tracking
- Logistics & Shipping: carriers, destination and delivery status
- Analytics & Reports: charts, supplier rating overview and inventory valuation
- CSV export for tables/reports
- Login/Register demo interface (frontend only)
- Dark mode toggle
- Responsive sidebar and layout for mobile/tablet/desktop
- Data persistence using browser localStorage; no database required

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in Chrome/Edge, or open the folder in VS Code and run it with Live Server.
3. Internet is needed for Google Fonts and Chart.js CDN charts. Core pages still render if charts are offline.

## Notes
- This is a frontend-only demo, not a production application.
- Login/Register is a visual demo and does not provide real server-side authentication.
- Records are saved in the current browser using localStorage. Use the same browser to see saved changes.
- Sample data is included so the dashboard looks populated immediately.
